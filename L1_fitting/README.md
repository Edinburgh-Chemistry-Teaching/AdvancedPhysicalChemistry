# Lecture 1: From fitting to learning

*Optional notebook, about 45–60 minutes.*

[`L1_fitting_colloids.ipynb`](L1_fitting_colloids.ipynb): non-linear fitting with examples from the colloids part of the course. You first fit Jean Perrin's 1909 sedimentation counts of gamboge grains to get Avogadro's constant, and compare the result with a linearised fit. You then fit dynamic light scattering (DLS) correlation functions of silica particles: one decay curve (starting guesses and residuals), then the decay rates at nine angles, which give the diffusion coefficient and, via Stokes–Einstein, the particle size. The DLS data are simulated (see [`../data/README.md`](../data/README.md)).
